How to Make a WiFi QR Code: Let Guests Connect Without Typing the Password

Every home, café, office and classroom has the same small problem: a guest asks for the WiFi password, and someone has to spell out a long, messy string of letters and numbers — often twice. A WiFi QR code removes that friction. Your guest points a phone camera at a printed code, taps once, and is connected. This guide explains what a WiFi QR code is, how to create one for free in under a minute, and how to use it safely.

What Is a WiFi QR Code?

A WiFi QR code is a normal QR code that stores your network name (SSID), your password, and the security type your router uses (usually WPA2). When a modern Android or iPhone camera scans it, the phone recognises the format and shows a "Join network" prompt. Nothing is installed and nobody has to type anything — the code simply carries the same details you would otherwise dictate out loud, in a form phones can read instantly.

This is why hotels, restaurants, clinics and offices print these codes at the reception desk or on tables. It works just as well at home, on the fridge or near the router.

Security Tips Worth Following

A WiFi QR code shares your password with anyone who can see it, so treat it like the password itself. A few sensible habits:

  • Use a guest network if your router offers one. Most modern routers can create a separate guest SSID with its own password. Put the guest password in the QR code, and your main network — with your laptops, phones and files — stays private.
  • Keep WPA2 or WPA3 security on. Never create a code for an open, unencrypted network, and avoid the old WEP option; it can be cracked in minutes.
  • Control where the code lives. Inside your home or shop is fine. Do not post a photo of your home WiFi QR code on public social media.
  • Change the password occasionally. If a printed code has been in a busy public place for a year, rotate the password and print a fresh code.

Printing and Placement Tips

Print on plain white card with the code in black — fancy colours and busy backgrounds reduce scanning reliability. Keep a quiet white margin around the code; scanners need it. If the code will sit near a window or in a café, laminate it so sunlight and spills do not fade it. A short caption helps first-time users: "Point your camera here to connect to our WiFi." In a larger place, print one code per room.

A Worked Example: A Café Sets Up Its WiFi Code

To make the steps concrete, here is how a small café might do it in practice. The owner opens the router's settings and creates a guest network named BeanThere Guest with its own password, separate from the network the till and office laptop use. In the generator she selects WPA/WPA2, types the network name exactly as BeanThere Guest — capitals and the space included — and enters the guest password character by character. She downloads the PNG, then tests before printing: on her own phone she "forgets" the guest network, scans the downloaded code from her computer screen, and confirms the phone offers to join and connects. Only then does she print the code at about 4 cm square on plain cards with the line "Scan to join our WiFi" underneath, and place one on each table. Three months later, when she rotates the guest password, she repeats the same ten-minute routine and swaps the cards — the old codes stop working because the password inside them is no longer the password on the router.

Common Mistakes That Stop a Code Working

  • The password changed on the router, but the printed code did not. A WiFi QR code is a photograph of the details at the moment it was made. Change the password and every printed copy is instantly out of date.
  • A subtle typo in the network name. Phones match the SSID exactly. "Home_Wifi", "Home-Wifi" and "Home Wifi" are three different networks as far as a phone is concerned.
  • Printing the code too small. Below about 2.5–3 cm, cheaper phone cameras struggle, especially in dim light. Bigger is always easier to scan.
  • Testing on a phone that is already connected. A phone that knows the network will appear to "scan fine" even if the password in the code is wrong. Always test on a phone that has forgotten the network.
  • Laminating with glossy plastic and placing it in sunlight. Glare defeats cameras. Matte lamination, or a spot out of direct sun, scans far more reliably.

Frequently Asked Questions

Do guests need a special app to scan a WiFi QR code?

No. The built-in camera app on almost all modern Android phones and iPhones (iPhone X and later, and most recent Android devices) recognises WiFi QR codes and offers to join the network directly.

Is it safe to enter my WiFi password into an online generator?

Only use a generator that works inside your browser without uploading data. The Loona generator creates the code on your own device, so your password never leaves your phone or computer. Never use a site that demands an account just to make a WiFi code.

The code scans but does not connect. What is wrong?

Almost always a typing mistake: a wrong capital letter, a space, or the wrong security type. Re-enter the password exactly as it appears in your router settings, and make sure you did not pick WEP for a WPA2 network. Also delete ("forget") the network on the test phone before rescanning.

Can one QR code work for both my home and shop?

Only if both places use the same network name and password, which is not recommended. Make a separate code for each network — for a business, always use the guest network.

My router has both 2.4 GHz and 5 GHz networks. Does the code still work?

Yes — the code simply joins whichever network name it contains. If your router shows one combined name for both bands (the common modern setup), one code covers both. If the bands have separate names, make one code for the name you want guests to use; the 2.4 GHz band is usually the friendlier choice because it reaches further through walls.

Does a WiFi QR code ever expire?

No. The code is not stored on any server and there is no account behind it — it works for exactly as long as the network name and password stay unchanged.
